AMR Surveillance Data Quality Standards Guide

This guide outlines surveillance data integrity principles aligned with CLSI M100, EUCAST, and the WHO Global Antimicrobial Resistance and Use Surveillance System (GLASS).

1. Completeness (Current: 98.6% · Target ≥ 95.0%)

Measures the presence of mandatory surveillance attributes. Every record must specify isolate ID, specimen collection date, originating state, specimen source, canonical organism, and antimicrobial agent. Records with nulls in critical clinical fields are flagged for laboratory review.

2. Consistency (Current: 97.2% · Target ≥ 95.0%)

Ensures cross-field semantic validity. Cross-checks organism taxonomy against antibiotic testing panels (e.g., verifying vancomycin is not tested on Gram-negative bacilli) and standardizes administrative names (e.g., standardizing 'Karntaka' to 'Karnataka').

3. Validity (Current: 95.8% · Target ≥ 95.0%)

Validates clinical data values against canonical format boundaries. Resistance percentages must strictly fall between 0.0% and 100.0%. Minimum Inhibitory Concentrations (MIC) and disk diffusion diameters must comply with CLSI M100 interpretive criteria.

4. Timeliness (Current: 96.1% · Target ≥ 95.0%)

Monitors ingestion latency from AST culture confirmation to central repository sync. Benchmark target is ≤ 72 hours for acute pathogens (e.g., Carbapenem-Resistant Enterobacterales) to ensure early outbreak warning capabilities.
